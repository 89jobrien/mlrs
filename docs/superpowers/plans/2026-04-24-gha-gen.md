# gha-gen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Rust library that models and emits GitHub Actions workflow YAML for reusable
workflows and composite actions.

**Architecture:** Single crate `gha-gen` with two internal modules — `model` (typed structs,
typed_builder) and `emit` (serde_yaml serialization + custom serializers for GHA quirks).
No binary, no file I/O. Public surface is `.to_yaml()` on `Workflow` and `CompositeAction`.

**Tech Stack:** Rust, `serde`, `serde_yaml`, `typed_builder`, `indexmap`, `insta` (snapshot
tests), `thiserror`

  ```rust
  use serde::{Deserialize, Serialize, Serializer};
  use typed_builder::TypedBuilder;

  /// The type of a workflow_call or composite action input.
  #[derive(Debug, Clone, PartialEq, Eq, Deserialize)]
  pub enum InputType {
      String,
      Boolean,
      Number,
      Choice(Vec<String>),
  }

  impl Default for InputType {
      fn default() -> Self {
          Self::String
      }
  }

  // GHA requires the type field to be a plain string ("string", "boolean", etc.)
  // not the enum variant name, and Choice doesn't embed the options in the type value.
  impl Serialize for InputType {
      fn serialize<S: Serializer>(&self, s: S) -> Result<S::Ok, S::Error> {
          match self {
              InputType::String => s.serialize_str("string"),
              InputType::Boolean => s.serialize_str("boolean"),
              InputType::Number => s.serialize_str("number"),
              InputType::Choice(_) => s.serialize_str("choice"),
          }
      }
  }

  /// A single input definition for workflow_call triggers or composite actions.
  #[derive(Debug, Clone, Serialize, Deserialize, TypedBuilder)]
  #[serde(rename_all = "kebab-case")]
  pub struct Input {
      #[builder(default)]
      #[serde(rename = "type", skip_serializing_if = "is_string_type")]
      pub input_type: InputType,
      pub description: String,
      #[builder(default = false)]
      pub required: bool,
      #[builder(default, setter(strip_option))]
      #[serde(skip_serializing_if = "Option::is_none")]
      pub default: Option<String>,
      /// Only present when input_type == Choice. Serialized as top-level "options" key.
      #[builder(default, setter(strip_option))]
      #[serde(skip_serializing_if = "Option::is_none")]
      pub options: Option<Vec<String>>,
  }

  fn is_string_type(t: &InputType) -> bool {
      *t == InputType::String
  }

  /// An output entry in a composite action.
  #[derive(Debug, Clone, Serialize, Deserialize)]
  pub struct ActionOutput {
      pub value: String,
      pub description: String,
  }
  ```

  ```rust
  use serde::{Deserialize, Serialize};
  use typed_builder::TypedBuilder;

  /// The body of a step — either a `uses:` action reference or a `run:` shell script.
  /// These are mutually exclusive in GHA YAML; the enum enforces this at compile time.
  /// The variants flatten into the parent Step during serialization.
  #[derive(Debug, Clone, Serialize, Deserialize)]
  #[serde(untagged)]
  pub enum StepBody {
      Uses {
          uses: String,
          #[serde(default, skip_serializing_if = "IndexMap::is_empty")]
          with: IndexMap<String, String>,
      },
      Run {
          run: String,
      },
  }

  /// A single step within a job or composite action.
  #[derive(Debug, Clone, Serialize, Deserialize, TypedBuilder)]
  #[serde(rename_all = "kebab-case")]
  pub struct Step {
      #[builder(default, setter(strip_option))]
      #[serde(skip_serializing_if = "Option::is_none")]
      pub id: Option<String>,

      #[serde(rename = "if", skip_serializing_if = "Option::is_none")]

      pub body: StepBody,

  }
  ```

  Actually, `typed_builder` with a custom setter for `runs` is complex. Use a simpler
  approach: accept `steps: Vec<Step>` directly in the builder and construct `CompositeRuns`
  in a `build()` post-processing step. The cleanest way with `typed_builder` is to accept
  an `Option<Vec<Step>>` and convert:

  ```rust
  use indexmap::IndexMap;
  use serde::{Deserialize, Serialize};
  use typed_builder::TypedBuilder;

  use crate::model::{input::{ActionOutput, Input}, step::Step};

  #[derive(Debug, Clone, Serialize, Deserialize)]
  pub struct CompositeRuns {
      pub using: String,
      pub steps: Vec<Step>,
  }

  /// A GitHub Actions composite action (`action.yml`).
  #[derive(Debug, Clone, Serialize, Deserialize)]
  pub struct CompositeAction {
      pub name: String,
      pub description: String,
      #[serde(skip_serializing_if = "Option::is_none")]
      pub author: Option<String>,
      #[serde(skip_serializing_if = "IndexMap::is_empty")]
      pub inputs: IndexMap<String, Input>,
      #[serde(skip_serializing_if = "IndexMap::is_empty")]
      pub outputs: IndexMap<String, ActionOutput>,
      pub runs: CompositeRuns,
  }

  /// Builder for `CompositeAction`.
  /// Uses a plain builder (not typed_builder) because the `runs` field
  /// is derived from `steps` at build time.
  #[derive(Default)]
  pub struct CompositeActionBuilder {
      name: Option<String>,
      description: Option<String>,
      author: Option<String>,
      inputs: IndexMap<String, Input>,
      outputs: IndexMap<String, ActionOutput>,
      steps: Vec<Step>,
  }

  impl CompositeActionBuilder {
      pub fn new() -> Self { Self::default() }
      pub fn name(mut self, v: impl Into<String>) -> Self { self.name = Some(v.into()); self }
      pub fn description(mut self, v: impl Into<String>) -> Self { self.description = Some(v.into()); self }
  ```
